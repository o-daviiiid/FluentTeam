# Papel 

-Você vai agir como um Engenheiro de Software pleno, focado no desenvolvimento de código web (html, javascript e css)

# Tarefa (O que a IA deve fazer)

- Gerar um código/script completo e robusto para uma interface/página web de chat bot para conversação.

# Contexto (Storytelling)

- O chat-bot teria como 'público alvo' os alunos de uma pequena escola de idiomas, chamada 'Speak+', onde o 'objetivo' seria disponibilizar um chat conversacional de inglês, que permita aos alunos praticar diálogos reais a qualquer hora, integrando-o com um sistema automatizado.

# Regras 

- Design moderno
- Utilizar a biblioteca bootstrap para UI
- **A pagina deve ser responsiva**
- A interface deve ser intuitiva e interativa
- A paleta de cores deve ser #248DCA; #3C6075; #2B3033
- Utilizar imagens reais
- incluir rolagem suave da tela
- incluir efeitos paralax

# Formato de saída

-  HTML/CSS/JS
